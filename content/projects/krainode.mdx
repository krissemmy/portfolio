I built KraiNode to make JSON-RPC requests easier to reproduce and inspect in a browser. It provides a playground for sending requests to blockchain RPC endpoints and examining the responses and timing, so another engineer can repeat the same check.

[Open KraiNode](https://krainode.krissemmy.com/) or explore the source code linked above.
